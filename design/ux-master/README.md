# 维叙 UX 母版

> 文档导航：[交互、主题与视觉索引](../../doc/indexes/design.md) · [总索引](../../doc/INDEX.md)

更新：2026-09-23。设计起点为已通过的剧情图样机；本目录维护后续开发使用的结构化 UX 母版。

## 打开与使用

- [fablevia-ux-master.pen](fablevia-ux-master.pen)：可编辑母版，包含共享组件、设计变量、页面和控件状态。
- [母版预览](index.html)：浏览全部画板，可按基础组件、主要页面、补充状态筛选，也可搜索编号或名称。
- [画板目录](catalog.json)：PenCLI 读取母版后导出的编号、图层 ID、状态和预览路径。
- [原始图片图册](../../spec/assets/graph-editing-ux/gallery.html)：保留已通过的视觉起点，后续细节以结构化母版及本说明为准。

布局、组件外观和状态查看 `.pen`；行为与数据边界同时对照 [编辑器 UX 规范](../../spec/design-brief-editor-ux.md)。代码实施状态只维护在 [progress.md](../../spec/progress.md)。母版中的示例故事与数值用于展示状态，不是用户数据或运行时结果。

## 文件结构

| 文件或目录 | 用途 |
|---|---|
| fablevia-ux-master.pen | 设计编辑的主文件 |
| previews/ | 从母版导出的原尺寸 PNG |
| index.html | 离线可浏览的母版图册 |
| catalog.json | 画板与导出文件的对应关系 |
| build-preview.mjs | 根据 catalog.json 更新离线图册 |

`.pen` 使用 PenCLI 或 Pencil 工具读取和修改，不按 JSON 打开、搜索或手工改写。后续修改从当前画布读取图层，优先更新共享组件或对应页面。

## 画板组织

母版包含 70 个页面状态和 8 张基础／组件图谱。原图册的 01–20 编号保持对应；21–70 补充实际操作状态。所有页面均由命名图层组成，控件和公共外壳使用共享实例；图片仅用于导出预览，不作为页面内容嵌入母版。

基础区从设计变量开始，依次为组件母版、按钮与输入状态、选择与反馈状态、工作台公共结构、剧情节点与端口、交互组合状态、列表卡片与浮层状态。页面区按编号排列在基础区下方。

## 控件状态与规则

| 控件 | 母版中的适用状态 |
|---|---|
| 主按钮、次按钮、文字按钮、危险按钮、图标按钮 | 默认、悬停、按下、键盘焦点、禁用、加载 |
| 文本、数字、选择器、搜索输入 | 空白、已填写、悬停、焦点、错误、禁用、只读；展开面板另含读取中、失败、无结果 |
| 多行输入 | 空白、已填写、悬停、按下、焦点、错误、只读、禁用 |
| 复选框、单选框、开关 | 未选、已选、悬停、按下、焦点、禁用、禁用且已选 |
| 标签、导航、菜单、折叠区 | 默认、悬停、按下、焦点、选中、禁用、展开 |
| 列表行、变量项、格式卡片、主题卡片 | 默认、悬停、按下、焦点、选中、禁用 |
| 剧情节点 | 默认、悬停、选中、焦点、拖动、错误 |
| 路线、端口、连接线 | 默认、悬停、选中或可连接、焦点或拖动、未连接、无效、已连接（按控件适用） |
| 提示与工具提示 | 信息、成功、警告、错误；工具提示包含隐藏、悬停显示、焦点显示 |
| 组合状态 | 焦点与悬停、焦点与错误、焦点与选中、加载且不可重复触发 |

交互状态从图层名称及其所在状态列识别。PenCLI 当前版本对实例附加元数据的保留有限，因此实例状态不依赖不可见的元数据覆盖；以可见状态图谱、图层名称和本文行为规则为准。

- 加载与禁用阻止重复触发；未实现取消机制的提交过程不提供可点击的关闭／取消动作。
- 焦点轮廓独立于选中与悬停颜色。危险按钮的按下状态继续使用危险色，不变成普通主操作色。
- 只读内容可以选择复制，显示正常文本与锁定提示；禁用内容弱化，不参与编辑。
- Enter 在输入法选词期间只确认文字。未完成的数字草稿保留，不立即改成 0，也不退回源码表单。
- 表单错误就近显示原因和修正方式；按钮禁用不能成为唯一解释。
- 弹层在可用区域内展开，关闭后返回触发控件；菜单使用方向键与 Enter，模态对话框约束焦点范围。
- 同一剧情内的普通输入不改变控件身份。无效草稿阻止会丢失它的切换操作，并提供返回修改或明确放弃的选择。

## 本轮设计修正

在制作可编辑布局时，统一了变量计数与新建草稿的区别、条件比较与变量变化的分组、只读和禁用的区别，以及危险按钮按下状态。移除了没有功能的拖动手柄，调整了弹层高度和窄窗口布局，避免按钮越界；补充了文件夹、语言与引用中变量删除等原图册未单列的操作。

节点变更通过现有故事命令层写回 `.mdstory`。数值变化只展示现有设值、增减能力；文本可以设值和末尾添加；开关与固定选项只展示设值。组合数据选择具体项目，不能整体赋值。上述设计不新增公式语法、远程主题或强制联网创作能力。

## 后续编辑与同步

在项目根目录可使用本机已安装的 PenCLI 打开母版：

```powershell
pen.cmd interactive --in design/ux-master/fablevia-ux-master.pen --out design/ux-master/fablevia-ux-master.pen
```

进入交互 shell 后先读取 `read_skill()`、`read_skill({path:"pen-schema.md"})` 和 `read_skill({path:"execute.md"})`，再用 `get_app_state()` 定位当前画布。使用 `execute` 更新图层，通过 `Get` 核对结构、`TakeScreenshot` 核对外观，最后 `save()`。不要直接编辑加密文件。

更新画板后，使用 PenCLI 的 `Export` 更新 previews，并同步 catalog.json 中受影响的画板条目，再运行 `node.exe design/ux-master/build-preview.mjs`。新增或改变页面职责时同步本文映射与设计分类索引；行为合同有变化时同步 UX 规范。母版及预览属于正式设计资产，不按临时测试输出清理。
