# 官网设计基线

> 文档导航：[交互、主题与视觉索引](../doc/indexes/design.md) · [总索引](../doc/INDEX.md)

本文件维护下一阶段官网方向，不表示新设计已经实现。当前实现入口是 website/src，静态降级入口是 website/static；实际版本与开发状态分别来自根 package.json 和 spec/progress.md。

## 定位与叙事

面向 1—5 人独立游戏团队，核心表达是“把分支故事画清楚，再把干净数据交给引擎”。先解释 Graph Lab 图形创作，再展示 .mdstory 可读源码与导出结果，最后呈现主题、使用说明和获取入口。

中文品牌以维叙为主、Fablevia 为辅助，英文只显示 Fablevia。品牌性格为安静、精密、有想象力；视觉方向为原生创作工作台与生长的分支结构，不采用游戏 HUD 或通用 SaaS 卡片模板。

## 首页结构

1. 首屏说明产品与受众，使用真实 Graph Lab 工作区图和明确行动入口。
2. 用一个小故事展示创建节点、连线、条件、诊断和导出的连续过程。
3. 展示图形编辑与 .mdstory 源码对应关系，解释文件所有权与 Git 友好。
4. 以 JSON 程序交接、HTML 试玩、TXT 校对说明三种导出用途。
5. 展示三套真实内置主题及 Godot 接入层级，再提供帮助与获取入口。

现有主按钮仍是使用说明和开发页；新产品演示与公开下载入口尚未实现。只有目标页面或文件真实存在时才接入相应按钮。

## 视觉与交互方向

- 明亮底色与品牌蓝组织层级，语义强调色低频使用；实现颜色统一进入官网 token。
- 使用中文质量可靠的无衬线正文；等宽字体用于源码、JSON 和快捷键。字体选择核对覆盖范围与许可。
- 首屏可采用不对称构图与真实产品窗口，不把全部内容排成同形卡片。
- 动效用于分支连接、聚焦和轻量过渡，提供 reduced-motion，不妨碍阅读或点击。
- 覆盖 1440、1024、390px 与中英真实字长；手机优先保留主价值、演示和行动入口。
- 新版中英页面采用独立可索引 URL，并分别维护标题、description、canonical、hreflang 和分享图。现有客户端语言切换尚不等于这一目标。

## 可复用资源与待决定事项

打包图标来自 [build/icon.png](../build/icon.png) 及 build/app-icons；源图见 [资源说明](../build/README.md)。应用 Home 与官网当前使用各自 assets/public 中的 fablevia-icon.svg，与打包位图并非同一视觉版本。统一品牌图标属于需要用户决定的视觉方向，不机械替换。

主题真实预览位于 packages/app/src/theme/builtin 下的 assets。官网专用 Graph Lab 截图、短演示和分享图可从实际产品场景制作。

产品价格策略为 $29 买断；币种、许可、购买与分发入口按具体商业交付确定。本阶段不虚构评价、用户量、客户案例或不存在的下载链接；首页不放内部验收解释。

## 实现边界

保持独立 React/Vite 项目和静态部署，不进入桌面安装包；不默认新增数据库、CMS、账号或分析服务。普通页面实现直接推进，不以另建计划文档为前置条件。产品定位、品牌图标方向或商业模式变化再由用户决定。
